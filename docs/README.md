# pisynth docs

**👤 = for everyone (installing & using it) · 🔧 = for developers (hacking on it).**

- 👤 **[install.md](install.md)** — step-by-step install: flashing & Imager preconfig, the two
  install paths (laptop / on-device), Windows/WSL, soundfonts, troubleshooting.
- 👤 **[bluetooth.md](bluetooth.md)** — pairing a Bluetooth speaker / wireless MIDI device

- 🔧 **[dev.md](dev.md)** — developer guide: the deploy/migration workflow, the
  screenshot/remote-control feedback loop, and the menu-UI SDK.
- 🔧 **[preferences.md](preferences.md)** — reference for the `settings.yaml` preferences file.
- 🔧 **[optimization.md](optimization.md)** — tuning the Pi 3B+ for glitch-free, low-latency fluidsynth.
- 🔧 **[research.md](research.md)** — design rationale & the decision log.
- **[roadmap.md](roadmap.md)** — planned / deferred work (hardware mods, perf tuning).

The project landing page is the [repo README](../README.md). Hardware (the SPI panel) is
configured in [`../hardware.conf`](../hardware.conf).
