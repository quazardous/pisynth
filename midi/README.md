# Your MIDI files

Drop `.mid` / `.midi` files here (subfolders are kept, e.g. `midi/jazz/…`), then run
`./deploy.sh`: they appear in the Pi's MIDI library, next to the `starter/` set and the files
uploaded from the web companion. Everything in this folder except this README is gitignored.

Delete a file here and deploy again to remove it from the library. Files uploaded from the phone
are never touched by a deploy.
